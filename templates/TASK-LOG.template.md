# TASK-LOG (PDCA ledger)

> Discipline: every task (especially every subagent package) appends one PDCA
> entry on completion. No Check evidence = task not done.
> Scorekeeping: PASS +1 promotes the reusable practice into project
> instructions / memory / templates; FAIL -1 writes a one-line lesson that
> later briefs must cite by name ("lessons learned").
> Entries are append-only; the scoreboard header line is owned by the main
> session, not by subagents. Rework is a NEW entry, never an edit of an old one.

## Scoreboard
PASS 0 / FAIL 0
